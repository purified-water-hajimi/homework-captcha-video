# 把动物验证码接入选课系统（3 步）

> 目标项目：`servlet-course-separated`（Tomcat 9 + javax.servlet）
> 改完效果：登录页多一张动物图片，用户要输入图中动物名，答对才能登录。

---

## 第 1 步：放进后端

把 `CaptchaServlet.java` 复制到：

```
backend/src/main/java/demo/course/servlet/CaptchaServlet.java
```

它自带 `@WebServlet("/api/captcha")`，**不用改 web.xml**，容器会自动注册。

---

## 第 2 步：登录时校验

打开 `backend/src/main/java/demo/course/servlet/AuthServlet.java`，找到 `/api/login` 分支：

```java
User user = auth.login(request.getParameter("username"), request.getParameter("password"));
```

在它**前面**插入：

```java
// 动物验证码：先校验，再验证账号密码
if (!CaptchaServlet.verify(request.getSession(false), request.getParameter("captcha"))) {
    HttpJson.write(response, 400, new ApiResponse("CAPTCHA_WRONG",
            "动物验证码不正确，请刷新后重试。", null));
    return;
}
```

⚠️ 顺序很重要：**验证码放前面**，这样错的账号密码不会白白消耗数据库查询，
也避免别人拿它当密码爆破接口。

---

## 第 3 步：前端加图片和输入框

### 3.1 `frontend/login.html`

在密码输入框下面加：

```html
<label for="captcha">动物验证码</label>
<div style="display:flex;gap:10px;align-items:center;margin-top:6px">
  <img id="captchaImage" src="api/captcha" alt="动物验证码"
       style="height:52px;border:1px solid #d6dde6;border-radius:8px;cursor:pointer">
  <button type="button" id="captchaRefresh">换一张</button>
</div>
<input id="captcha" name="captcha" autocomplete="off"
       placeholder="请输入图中的动物名称" required>
```

### 3.2 `frontend/assets/js/login.js`

在文件末尾加：

```js
// 点击图片或按钮都重新拉一张（加时间戳避免浏览器缓存）
const captchaImage = document.getElementById("captchaImage");
const captchaRefresh = document.getElementById("captchaRefresh");
function refreshCaptcha() {
  captchaImage.src = "api/captcha?t=" + Date.now();
}
captchaImage.addEventListener("click", refreshCaptcha);
captchaRefresh.addEventListener("click", refreshCaptcha);
```

然后把登录调用改成带 `captcha` 参数：

```js
await api.login(username.value.trim(), password.value,
                document.getElementById("captcha").value.trim());
```

### 3.3 `frontend/assets/js/api.js`

`login` 方法里补一个参数并塞进请求体：

```js
login(username, password, captcha) {
  return request("/api/login", {
    method: "POST",
    body: new URLSearchParams({ username, password, captcha: captcha || "" })
  });
}
```

**失败后要刷新图片**（因为服务端一次即作废）：

```js
} catch (error) {
  errorText.textContent = error.message || "登录失败，请稍后重试。";
  errorText.hidden = false;
  refreshCaptcha();          // ← 加这一行
  password.focus();
}
```

---

## 为什么这么做（可以写进实验报告）

| 设计点 | 原因 |
|---|---|
| 答案只存 Session | 前端拿不到答案，改 DOM 没用 |
| 一次性消费 | 每次校验后立刻删除，防止同一张图反复试 |
| 3 分钟过期 | 防止爬虫慢慢穷举 |
| 先验验证码再验密码 | 少一次数据库查询，且挡掉批量撞库 |
| 干扰动物半透明 | 增加识别难度，但不影响人类判断 |
