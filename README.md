## 一、动物验证码

### 做了什么

登录页多一张图，图里是一只随机动物（猫/狗/熊猫/兔子/狐狸/青蛙/老虎/狮子/考拉/企鹅），
用户要**输入动物名字**才能登录。

### 两个版本

| 版本 | 文件 | 用途 |
|---|---|---|
| **演示版** | `demo/login-demo.html` | 双击就能看，纯前端，适合演示和截图 |
| **正式版** | `java/CaptchaServlet.java` + `接入说明.md` | 接进你现有的 `servlet-course-separated` 项目 |

### 演示版怎么用

1. 双击 `demo/login-demo.html`
2. 看图——最大的那只动物是什么
3. 在输入框填名字（「猫」「猫咪」「cat」都认）
4. 填对 → 提示验证通过；填错 → 自动换一张

### 安全性设计（可以写进实验报告）

| 做法 | 目的 |
|---|---|
| 答案只存在服务端 Session | 前端改 DOM 也没用 |
| 一次性消费 | 校验后立刻删除，防重放 |
| 3 分钟过期 | 防慢速穷举 |
| 先验验证码再验密码 | 挡掉批量撞库 |
| 干扰动物 + 噪点 + 曲线 | 增加 OCR 难度 |

## 二、视频站（带插播广告）

### 做了什么

一个在线视频播放页，**每播放 180 秒插一次广告**：

- 广告 8 秒，**5 秒后可以跳过**
- 暂停视频，计时也暂停（不占你便宜）
- 广告看完自动续播
- 可以**选本地视频文件**播放（不用联网也能演示）

### 怎么用

1. 双击 `02-视频站/index.html`
2. 点「播放」（默认加载一个测试视频）
3. 或者点「选择本地视频」，放你自己电脑里的 mp4
4. 等 180 秒（或者临时把代码里的数字改小），广告就出来了

### 改参数

打开 `index.html`，搜索这三行，改成你要的数值：

```js
const AD_INTERVAL_SECONDS = 180;  // 每多少秒插一次
const AD_DURATION_SECONDS = 8;    // 广告多长
const SKIP_AFTER_SECONDS  = 5;    // 几秒后能跳过
```

演示时建议改成 `30 / 8 / 3`，不然要等三分钟。

### 广告素材

在 `ADS` 数组里，四组文案随便改：

```js
{ title: "标题", text: "副标题" }
```

### 为什么这么设计（可写进报告）

| 设计 | 原因 |
|---|---|
| 按「**播放时长**」计时，不是真实时间 | 暂停时不该算，否则用户体验很差 |
| 广告可以 5 秒后跳过 | 保留广告收益，又不至于让人关掉 |
| 广告期间禁用播放按钮 | 防止绕过广告 |
| 看完广告重置计时 | 避免连着弹两个 |
| 广告是覆盖层不是新页面 | 不打断播放进度，体验更连贯 |

## 四、如果老师要求「必须跑在服务器上」

这两个页面都是**纯静态**，部署非常简单：

```bash
# 把整个文件夹丢进 Tomcat 的 webapps 下
cp -r 作业-动物验证码与视频站 D:\apache-tomcat-9.0.123\webapps\
```

然后访问：

```
http://localhost:8090/作业-动物验证码与视频站/01-动物验证码/demo/login-demo.html
http://localhost:8090/作业-动物验证码与视频站/02-视频站/index.html
```

⚠️ Tomcat 默认对中文路径可能有编码问题，稳妥起见**把文件夹改成英文名**（比如 `homework-captcha-video`）再放。
